# Interface screenshots

These images show the real Auto Compact client in the stock **Paseo 0.12.0 web app**, captured on **2026-10-22** in the light theme. The declared minimum Paseo support is 0.12; these captures establish the tested version only.

| File | Size | Content |
| --- | --- | --- |
| [conversations.png](conversations.png) | 1440 × 960 | Composer countdown and open controls: context usage, conversation switch, skip, manual compact and Settings. |
| [undo-skip.png](undo-skip.png) | 390 × 1000 | Mobile browser sheet after skipping, showing **Compact on**, disabled **Skip this time**, and **Undo skip**. |
| [settings.png](settings.png) | 1440 × 960 | Host settings with the default 200k threshold, 55-minute delay and Claude provider switches. |

Agents and workspace are disposable test records. Token counts, schedules and action results are seeded sample RPC data. These are not real user conversations or evidence of billing, cache retention or successful model compaction. The plugin client and host settings UI are real. Browser layouts at 390px and 375px and the dark theme were also checked; native iOS and Android apps remain unverified.
